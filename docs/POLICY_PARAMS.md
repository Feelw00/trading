# 정책 파라미터 — v0.3 부록 B 결재 문서

> **상태: 초안 v1 (2026-08-27) — 운영자 결재 대기.** 결재 전 모든 값은 계측·보고 전용이며
> 편입(R4)·집행(R5) 판정에 사용 금지("파라미터 없이 스크리너를 가동하지 않는다").
> 결재 시 이 문서가 버전 태깅으로 확정되고, 개정은 R7 루프를 통해서만(헌장 2).

## 1. R3 온도계 제안 파라미터 (`cycle/engine.py PROPOSED_PARAMS`)

| 파라미터 | 제안값 | 근거 |
|---|---|---|
| `band_low` (하단 존) | ≤ 0.30 | 리플레이에서 전기·전자 23~24년 저점, 화학 24~25년이 이 존에 포착 |
| `band_high` (과열) | ≥ 0.75 | 현재 시장 상단 국면(9개 섹터)이 일관 포착 |
| `min_band_points` | 3 | percentile 최소 표본 — 미만은 unknown(21~22년 전면 unknown이 정직 작동 증거) |
| `min_z_points` | 4 | 매출 z 최소 관측 |
| `secular_window` / `min_obs` | 8년 / 5년 | 매출 CAGR ≤ 0 → 구조적 사양(밴드 무관 제외) |
| 온도 | (PBR밴드+마진밴드)/2 ×100 | 보고용 합성 — 판정은 PBR 밴드+개선 모멘텀 |

판정 규칙(코드 고정, 파라미터 아님): 1차 축 결측=unknown · bottoming=하단+개선 ·
하단인데 개선 없음=declining · 개선 판정=마진 또는 매출 YoY의 전년 대비 상승.

## 2. 사이클 화이트리스트 후보 (PIVOT-5 — 결재 대상)

**편입 기준**: 설비투자 리드타임 · 가격 수용자(commodity) · 글로벌 수요 연동.

| 화이트리스트 산업 | KRX 버킷(밴드 단위) | 혼합 한계(고지) |
|---|---|---|
| 메모리반도체 | 전기·전자 | 삼성전자·하이닉스 시총 지배 — 사실상 메모리 대형주 밴드(장비주 혼합) |
| 화학·정유 | 화학 | 정유가 화학 버킷에 흡수 — v1 통합 운용 |
| 철강 | 금속 | 비철 혼합 |
| 해운·물류 | 운송·창고 | 물류 혼합 |
| 조선 | 운송장비·부품 | ⚠️ **자동차와 혼합 — 버킷 밴드 왜곡 큼**. v1 보류 또는 종목 큐레이션 필요(택1) |
| 건설기계 | 기계·장비 | 반도체 장비 일부 혼합 |
| 은행/증권(금리) | 금융·증권 | 금융업 매출액 계정 부재로 마진·매출 축 결측(증권 unknown) — PBR 축 중심, 보강 축 필수 |

**1단계 제외(비사이클·방어)**: IT 서비스·제약·일반서비스·유통·음식료·통신·전기가스 등 —
R3 계측은 전 섹터 계속하되 R4 편입 대상 아님. (현재 bottoming 1위가 IT 서비스인데도
편입하지 않는 것이 스코프 규율이다.)

**결정 요청 ①**: 조선 처리 — (a) v1 보류 (b) 종목 큐레이션 리스트로 정밀화.
**결정 요청 ②**: 위 표 승인 여부(수정 포함).

## 3. 실물 보강 축 매핑 (PIVOT-2 — 게이트 아님, 가점·조기 신호)

수동 입력 채널(`python -m trading.manual_input`)로 어댑터 확정 전 즉시 가동 가능. 제안 키:

| 산업 | metric 키(제안) | 지표 | 입력 주기 |
|---|---|---|---|
| 해운 | `shipping.bdi` / `shipping.scfi` | 운임지수 | 월 1회 |
| 메모리반도체 | `semis.dram_fixed` | DRAM 고정가(시장조사기관 공표) | 월 1회 |
| 화학·정유 | `chem.spread` / `oil.crack_margin` | 스프레드·정제마진 | 월 1회 |
| 철강 | `steel.spread` | 철강 스프레드(제품-원료) | 월 1회 |
| 조선 | `ship.newbuild_index` / `ship.orderbook` | 신조선가·수주잔고 | 월 1회 |
| 은행/증권 | `rates.spread_3y10y` 등 | 금리 스프레드(ECOS 자동화 후보) | 자동/월 |

**결정 요청 ③**: 키 체계 승인 + 운영자 월 1회 입력 리듬 수용 여부.

## 4. 리플레이 사이클 재선정 (PIVOT-7 ⑥ 개정 — 데이터 제약 반영)

시세 커버리지 2020~(data.go.kr 실측)으로 원안(튜닝=반도체 2016·화학 2015)은 PBR 축 재현
불가. 재선정안:

- **튜닝(관찰 완료)**: 전기·전자 2023 저점→2025 과열, 화학 2024~ 바닥권 — as-of 리플레이가
  선행 판정(declining→bottoming→overheated) 재현 확인(2026-08-27, `python -m trading.cycle --replay`).
- **검증(임계 고정 후 1회만, 재사용 금지)**: 후보 = 운송·창고 2024 저점 판정 or 금융
  2023→2025 전환. **결정 요청 ④**: 검증 사이클 택1.

## 5. 미결(후속 결재)

R4 스크리너 임계(섹터 내 PBR percentile·생존력·탈락 필터 연차·거버넌스 감점 폭/시효),
비중 상한·현금 버퍼, DCA 분할 개월수, veto 창 길이, 급락 재심사 임계(-25% 제안)·쿨다운,
P-12 코어 ETF 활성화 — Phase 3 산출물로 제안 예정.
