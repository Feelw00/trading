## 1. R3 온도계 제안 파라미터 (`cycle/engine.py PROPOSED_PARAMS`)

| 파라미터 | 제안값 | 근거 |
|---|---|---|
| `band_low` (하단 존) | ≤ 0.30 | 리플레이에서 전기·전자 23~24년 저점, 화학 24~25년이 이 존에 포착 |
| `band_high` (과열) | ≥ 0.75 | 현재 시장 상단 국면(9개 섹터)이 일관 포착 |

| `min_z_points` | 4 | 매출 z 최소 관측 |
| `secular_window` / `min_obs` | 8년 / 5년 | 매출 CAGR ≤ 0 → 구조적 사양(밴드 무관 제외) |
| 온도 | (PBR밴드+마진밴드)/2 ×100 | 보고용 합성 — 판정은 PBR 밴드+개선 모멘텀 |

하단인데 개선 없음=declining · 개선 판정=마진 또는 매출 YoY의 전년 대비 상승.

| ③ declining 처리 | v1 레거시로 보존(엔진 미산출, 기존 append-only 레코드 파싱용). 표시 "하강(구)" | 정렬 우선순위는 slowing과 동급(발동 존·unknown 뒤, 과열 앞) |

- 수동 판정이 유효하면 자동은 미개입(운영자 override 우선), 만료 시 자동 재판정
