## 1. R3 온도계 제안 파라미터 (`cycle/engine.py PROPOSED_PARAMS`)

| 파라미터 | 제안값 | 근거 |
|---|---|---|

**v2.8 개정(운영자 지시 2026-09-02) — 페이퍼 단순화(100주 일괄 + 매도 간격 확대):**

**v2.8 부기(운영자 정정 2026-09-02 오후) — 페이퍼는 "100주 투자"가 아니라 매매 가이드:**

**v2.10 개정(운영자 결재 2026-09-02) — 청산 종목 재등록(사이클 원장):**

운영자 원칙: **과거 실현이익은 가점도 감점도 아니다** — "전에 벌어서 안 산다"도
"전에 벌어서 또 산다"도 배제. 재등록은 신규 후보와 **완전히 동일한 게이트**
(코어 8축 → 심사 승인 유효 → 여력 ≥ +30%)만으로 결정되고, 페이퍼 이력은 등록
판단에 어느 방향으로도 입력되지 않는다.

| 항목 | 내용 |
|---|---|
| 등록 게이트 | 차단 대상을 "원장에 존재"에서 **"open 포지션 존재"**로 축소 — 청산 종목은 표준 게이트 통과 시 새 기준가·새 목표가로 재등록(자동 등록 포함) |
| 체결 원장 | fills에 **cycle 컬럼**(UNIQUE(symbol, cycle, trigger)) — 사이클별 분리 재생, 과거 사이클 실현 이력 보존. 구 스키마는 열림 시 자동 재구축(cycle 0) — fills는 파생 캐시라 정당 |
| 사이클 번호 | 저장하지 않고 파생: 해당 심볼의 이전 'closed' 행 수 — append-only 유지 |
| 쿨다운 없음 | 이익 보호 정리 직후라도 지표가 게이트를 다시 채우면 재진입 — 순수 지표 판단(보통은 정리 직후 여력 < +30%라 자연 차단, 충분히 싸지면 통과) |

**v2.6 개정(운영자 결재 2026-09-01) — 전면 자동화(스케줄 확정 + 자동 심사):**

운영자 지시: "그냥 자동으로 돌리자 — 심사도 결정적이니까". 슬롯은 기존 2개 유지(§5 헌법).

| 슬롯 | 체인(v2.6) |
|---|---|
| eod-v3 평일 18:00 | 시세→섹터→재무→수급→토스 + **밸류에이션(일간 승격 — PBR·여력은 시세 함수) + 페이퍼 마킹(일별 종가 재생)** |
| weekly-v3 토 09:30 | **지배주주지분 증분** → 밸류에이션 → 온도계 → 스크리닝 → **환원·분할 증분 → 자동 심사(rule-v1) → 페이퍼 자동 등록** → 다이제스트 |

자동 심사 규칙(rule-v1 — **순수 코드**, 절대금지 2 정합·LLM 없음):
- approve = 이익방향(영업) ≥ 0 ∧ ⚠매출급감 없음 ∧ 여력 ≤ +150% ∧ 리츠 아님
- 아니면 hold(결정론 조건 문구: 양전 확인 / 급감 원인 / 극단 여력 원인 / COLLECT-5)
- **veto는 자동 생성하지 않는다** — 규칙 밖 예외의 인간 채널로 존속(태그 승격 루프 유지)
- 수동 판정이 유효하면 자동은 미개입(운영자 override 우선), 만료 시 자동 재판정

수동으로 남는 것: veto·수동 override(선택), 토스 멤버십 스냅샷(분기), §6 결재류.
