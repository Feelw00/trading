작업 세션 부팅을 수행한다. **고정 순서**로 스킬을 실행:

1. **`collect-macro` 스킬** — 거시지표(금리·환율·유가·지수)를 **승인 소스(ECOS·공공데이터/KRX·FRED)로만** 수집해 SQLite 적재. **독자 웹서치 금지**, 환각 가드(출처·as_of 필수, 추측 금지) 준수.
2. **`work-boot` 스킬** — 히스토리(작업/트레이딩) 읽기 → 기본 동작 활성화 → 마지막 작업 → 다음 작업 제안.

마지막에 통합 부팅 보고를 다음 형식으로 출력:

```
## 부팅 — <YYYY-MM-DD HH:MM KST>
### 거시 백드롭 (방금 수집)
- 금리 / 환율 / 유가 / 지수  (각 값·출처, UNVERIFIED 여부)
### 활성 기본 동작
- (핵심 불변식 한 줄 요약)
### 마지막 작업
- …
### 다음 작업 제안
1. …  2. …  3. …
```
