작업 세션 부팅을 수행한다. **고정 순서**:

1. **콘솔 현재 날짜 확인** — `TZ=Asia/Seoul date '+%Y-%m-%d %H:%M (%a)'` 실행. **이 콘솔 날짜를 기준으로 판단**(모델 추정 날짜 신뢰 금지).

2. **`collect-macro` 스킬** — 최신 거시지표(코스피·코스닥·나스닥·S&P·SOX·환율·금리·유가)**만** 라이브 조회·적재. 그 외 데이터(전종목·공시·뉴스)는 수집하지 않는다.

3. **`work-boot` 스킬** — 그 외는 **DB에서 읽되, 미수집이면 부팅 중 자동 수집한다**: 전종목 시세 신선도 + **오늘자 뉴스 신선도** + **자동 사이클 점검(`drill.py --audit` — cron 16슬롯 가동 중)** + 오늘 스크리너 후보 + history.
   - **시세가 최근 거래일보다 뒤처지면 → `collect` 스킬을 즉시 실행**해 갭을 메운다(질문하지 않는다). 스크리너는 수집 후 계산.
   - **오늘 뉴스 미적재 + 키 있으면 → `collect-news` 스킬을 즉시 실행.** 키 없으면 수집 불가 — 키 안내만(COLLECT-3, 흉내내기 금지).
   - 사이클 WARN/FAIL이면 ⚠️ 잡명+사유 보고(라운드 재트리거는 하지 않는다 — 점검·보고만).
   - 공시 등 그 외 무거운 수집은 부팅에서 하지 않는다.

수집을 포함해 모든 단계가 끝난 뒤, 마지막에 통합 보고:
```
## 부팅 — <콘솔 날짜>
### 거시 백드롭 (방금 라이브)
- 코스피/코스닥/나스닥/SOX/환율/금리/유가
### 자동 사이클 (drill --audit)
- 16슬롯 판정 요약              (WARN/FAIL 시 ⚠️ 잡명+사유, 게이트웨이 생존 포함)
### 데이터 신선도
- 시세 DB 최신일 vs 최근 거래일       (부팅 중 자동 수집했으면 '수집함' 명시)
- 뉴스: 오늘자 적재 여부(N건/없음)    (부팅 중 자동 수집했으면 '수집함' 명시, 키 없으면 키 안내)
### 오늘 후보 (스크리너, DB)
- 상위 N + 섹터 태그
### 마지막 / 다음 작업
```
