# flows — 투자자별 거래실적(수급) 조회

최근 거래일의 투자자별 매매동향(개인/외국인/기관 순매수)을 시장(KOSPI·KOSDAQ) + 스크리너 후보 종목 단위로 보여준다.

> **소스 주의:** 데이터는 거래소(KRX) 집계 투자자별 거래실적이지만, 공식 KRX Open API에는 이 서비스가 없어 **KIS Open API 공식 TR**(`FHPTJ04160001`/`FHPTJ04040000`, OPEN_QUESTIONS COLLECT-2 갭① 해소)로 받는다. KRX 정보데이터시스템 직접 접근(비공식 스크래핑)은 쓰지 않는다.

## 절차 (결정론적 어댑터 — 하네스)
어댑터가 수집·요약을 전부 수행한다. 스킬은 트리거·전달만 — LLM은 데이터에 손대지 않는다:
1. `.env` 로드 후 `poetry run python -m trading.collectors.flows --report` 실행.
2. 어댑터가 KIS에서 최근 거래일 수급을 적재(`data/flows.sqlite`, append-only·멱등)한 뒤 요약을 출력:
   - `[시장]` KOSPI/KOSDAQ 개인·외국인·**연기금(기금)·기관(연기금外)** 순매수(억원)
   - `[후보 종목]` 스크리너 후보별 동일 분해(외국인 순매수 내림차순, 억원)
   - **`[당일 잠정]`(장중에만)**: KRX 정규장 시간이면 시세성 TR(`FHPTJ04030000`)로 당일 누계를 추가 출력 — 조회 시각 라벨 + "확정치 아님" 명시. 장외·휴장엔 자동 생략(적재도 안 함 — 잠정치는 표시 전용).
   - 연기금 = KIS `fund_*`(공식 라벨 "기금"), 그외 기관 = 기관계 − 기금(합산 관계 실관측 검증). 기금 필드 없는 행은 "기관계 … (연기금 분리불가)"로 표기(임의 산술 금지).
3. 출력을 그대로 보고. as_of(거래일)와 잠정 여부를 반드시 병기.

## 환각 가드 (COLLECT-3)
- **독자 웹서치 금지.** KIS 키 미설정·소스 실패 시 어댑터의 blocked/실패 메시지를 그대로 보고하고 다른 소스로 대체하지 않는다.
- 수급 데이터는 EOD 성격 — 장중에 호출하면 "오늘"이 아니라 **최근 마감 거래일** 기준이다. as_of가 말해주므로 임의로 "오늘"이라 칭하지 않는다.
- 출력에 없는 수치·해석을 만들지 않는다. 해석(예: "외인 순매도 전환")은 출력된 숫자 범위 안에서만.

## 비고
- 적재는 daily-eod 체인(16:05)이 매일 자동 수행 — 이 스킬은 온디맨드 조회용(수집 포함이라 무겁지 않음, 시장 2콜+후보 N콜).
- 특정 종목 심층 토론은 `/discuss <종목>` (factpack에 수급 5일치 포함됨).
