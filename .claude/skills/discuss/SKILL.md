# discuss — 종목 분석·토론

특정 종목을 **실데이터로 grounding**해 추이·포지션을 **적대적으로** 토론한다.
예측기가 아니라 **조건문(무효화·트리거) 생성기**(설계서 §6 "조건문 공장 + 규율 집행기").

## 0. 입력
종목(이름/코드) + (선택) 운영자가 가져온 **소문/뉴스/의도**(진입·이탈 고려).

## 1. Grounding (결정론 — 추측 금지)
1. `.env` 로드 후 `poetry run python -m trading.factpack --ticker <종목>` → 가격맥락(DB)+공시(DART)+재무(DART, 당기/전기 YoY)+섹터. 못 찾으면(DB 미수집) `/collect` 제안.
2. **거시 백드롭:** 최신 `.runtime/collect/<날짜>/macro_indicators.sqlite` 읽기(있으면). 없으면 `collect-macro` 제안.
3. **뉴스:** `.runtime/collect/<날짜>/news.sqlite` 에서 해당 종목 `entities`(srtn_cd) 조회(있으면). 없으면 `collect-news` 제안.
- **모든 사실에 출처·as_of 표기.** 없는 데이터는 "미수집"이라 말하고 **지어내지 않는다**.

## 2. 운영자 입력 분리 (환각가드)
- 운영자가 가져온 소문/뉴스는 **`[UNVERIFIED]`** 로 명시 표기. fact pack의 grounded 사실과 **절대 섞지 않는다.**
- 공시/뉴스로 교차확인되면 "확인됨(출처·as_of)", 안 되면 "미확인 — 소문" 유지. **공시에 없는 촉매를 지어내지 않는다.**

## 3. 적대적 분석 (반-아첨)
운영자 가설/소문을 **공격**한다(설계서 §6 표준 공격벡터):
- 신선도(데이터 stale?) · 교란변수 · 역사적 반례 · 수단-논제 정합성 · 컨센서스 할인(이미 가격에 반영?) · 타이밍-메커니즘 정합성.
- **동조 금지 — 약점을 먼저 말한다.** 데이터가 가설과 어긋나면 그렇다고 말한다.
- **데이터 아티팩트 점검**: 액면병합/분할로 모멘텀 왜곡 여부(크레오에스지 1251% 사례 — 공시의 변경상장/거래정지해제 확인).

## 4. 포지션 프레이밍 (예측 아님)
산출은 전망이 아니라 조건문(`ThesisRecord` 형태):
- **가설**: 한 줄 + 방향(long/short/flat).
- **진입 트리거**: 구체 조건 — **지정가/조건부만**(시장가 금지, 절대금지 #3).
- **무효화(이탈)**: 관측가능한 조건(깨지면 논제 폐기) — **필수**. 없으면 토론 미완.
- **시계(horizon)**: 거래일(스윙 기본 3~15일).
- **확신도**: 0~1, 근거에 비례(과신 금지).
- **리스크/잔여매물**: 수급(외인·기관)·신용·공매도는 **현재 수집 미배선**(OPEN_QUESTIONS 🔴 KRX/수급) → "수급 데이터 없음 — 판단 보류" 명시(추측 금지).

## 5. 토론 (인터랙티브)
- 운영자가 반박하면 grounded로 재응답. **새 사실 없이 결론 바꾸지 않는다.**
- 단정 금지: 확정 데이터로 확인이 필요한 지점(예: 장중 잠정 수급, 미확인 소문) 명시.

## 출력
grounded 브리핑(출처·as_of) → 적대적 분석(약점 먼저) → 조건문(가설/트리거/무효화/시계/확신도/리스크). 간결하게.

> **가드:** 수치 출처·as_of 필수 · 운영자 소문=`[UNVERIFIED]` 분리 · 시장가 금지 · 무효화 필수 · 반-아첨 · 수급 등 미수집은 "없음"으로(추측 금지).
