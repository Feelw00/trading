# collect-news — 뉴스 수집 (별도)

뉴스는 공시(`collect-disclosure`)와 **분리** — 함께 조회하면 무겁기 때문. 정성 촉매(테마·이슈·정책) 보강용.

## 상태: 미배선 (소스 미확정)
- **승인된 뉴스 소스 어댑터가 아직 없다.** 하네스(COLLECT-3)상 독자 웹서치 금지라, 소스 확정 전까지 **수집하지 않고 `blocked` 보고**한다.
- 후보 소스: 언론 RSS / 뉴스 API 등 — **재배포 약관·정확성 확인 후 어댑터화**(`docs/OPEN_QUESTIONS.md` 등록 대상).

## 절차 (소스 확정 후)
1. 후보/시장 키워드로 **승인 소스**에서 최근 뉴스 조회.
2. 헤드라인 + 요약 + 출처(URL) + 시각(KST) 정규화 → fact pack 보강.

> **하네스:** 승인 소스 어댑터만, 독자 웹서치 금지. 미확정 구간은 건너뛰고 blocked 보고(추측 금지).
