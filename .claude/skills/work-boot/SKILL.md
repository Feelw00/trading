# work-boot — 작업 세션 부팅 컨텍스트

부팅의 **컨텍스트 로딩·보고** 단계. 거시지표 수집은 `collect-macro`가 담당하며 `/boot`가 먼저 호출한다.

## 1. 읽기
- `history/work/CURRENT.md` (전체) — 진행 중·최근 완료·다음 후보.
- `history/work/archive/` 최근 1~2개 헤더 (필요 시).
- `history/trading/INDEX.md` 최근 N줄(가벼운 스캔). 상세(`events/*`)는 특별사건·포지션 모호 시에만 로드.
- 포인터: `docs/PROGRESS.md`(마일스톤 원장), `docs/OPEN_QUESTIONS.md`(🔴 미결정).
- CLAUDE.md·MEMORY.md는 세션에 이미 자동 주입 — **재독 불필요, 활성화만.**

## 2. 기본 동작 활성화 (체크리스트로 재선언)
- **페르소나:** 직설·보수적, 반-아첨, 무비판 동조 금지.
- **작업 게이트:** 마일스톤 AC 미충족 시 다음으로 넘어가지 않기. 작업 종료 시 `CURRENT.md`(+필요 시 PROGRESS) 갱신·롤오버.
- **안전 불변식:** 시장가 주문 코드 금지(지정가·조건부만) · 비밀값 하드코딩 금지 · 모든 타임스탬프 KST tz-aware · 모르는 외부 엔드포인트 추측 금지(→ OPEN_QUESTIONS).
- **수집(R0):** LLM 수집으로 전환됨 — 단 출처·as_of 필수, 추측 금지(환각 가드). (CLAUDE.md rule #2는 이 결정으로 갱신 중.)

## 3. 마지막 작업
- CURRENT "진행 중"·"최근 완료" + 최근 커밋 1~2개를 요약.

## 4. 다음 작업 제안 (1~3개)
- CURRENT "다음 후보" + PROGRESS "다음" + OPEN_QUESTIONS 🔴 에서 **구체 행동**으로.

## 출력
간결한 4단 보고. 자동 주입된 규칙을 장황하게 재설명하지 말 것.
