# 2026-07-11 — P-9 3단계: 스윙 트리거 발화분 → R3~R5 분석 자동 승격

## 배경
2단계까지 스윙 기회는 저녁 보고 노출 + `/discuss` 수동 흐름이었다. 3단계는 발화 종목을
그날 저녁 분석 체인에 자동 합류시켜 **트리거 → 페르소나 논제(R3) → 플레이북/결재(R5)** 를 닫는다.

## 산출
1. **`rounds/r3.py`** — `build_prompt`/`run_r3`에 `extra_lines` 파라미터: 코드 계산 컨텍스트를
   전 페르소나 슬라이스에 공통 주입. 비승격 종목 프롬프트는 불변.
2. **`reason_news.py`** —
   - `_swing_promotions(limit)`: 최신 스냅샷 트리거 발화 종목 → {srtn: 승격 근거 라인}.
     종목별 트리거 병합, **점수순 상한 `max_swing`(기본 5 — 비용 가드**, R3는 종목당 claude 3콜).
     스냅샷 없으면 빈 dict(승격 발명 금지).
   - `run(max_swing=5)`: 촉매 후보 + 스윙 승격 합류(dedupe). 승격 종목은
     "스윙 승격 근거(P-9, as_of): 기회 트리거 X 발화 · 스윙 품질 점수 N (코드 계산치)" 라인이
     R3 슬라이스에 들어가 **촉매가 없어도 grounded 분석** 가능(입력격리 원칙 유지 —
     외부 추론이 아니라 코드 계산치 제공).
3. R5는 무변경 — ThesisStore 소비 경로로 승격 논제가 자동 흘러 플레이북/OrderDraft 후보가 된다.
   이후는 기존 결재 흐름(저녁 보고 → 아침 arm-check 승인) 그대로.
